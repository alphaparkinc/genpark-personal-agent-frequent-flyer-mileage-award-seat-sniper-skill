## 🛠️ MCP Tools Exposed
- `evaluate_award_redemption_value`: Calculate Cents-Per-Point (CPP) value of airline award flight redemption against cash ticket baseline and taxes/fees.
- `find_optimal_credit_card_transfer_partner`: Identify best credit card rewards ecosystem (Amex, Chase, Citi, Capital One, Bilt) to transfer points with active bonus multipliers.

## 🚀 Installation & Usage
Run directly with pure Python standard library:
```bash
python -m genpark_personal_agent_frequent_flyer_mileage_award_seat_sniper_skill.server --test
```
